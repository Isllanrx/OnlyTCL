# Hardware Context: TCL Smart TV BeyondTV4

- SoC: Realtek RTD2851M (rtd288o), 4x ARM Cortex-A55 @ 1.3 GHz.
- GPU: ARM Mali-G31 MP2.
- RAM: 1.5 GB + 768 MB Swap ZRAM.
- Display: 1920x1080 @ 60 Hz.
- Media Decoder: `OMX.realtek.video.decoder`.
- Display Layer: HWC2 Realtek VSC (Video Surface Composer) supporting SurfaceView hardware composition (`DEVICE`).
