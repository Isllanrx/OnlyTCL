# tv-home (Custom Minimalist Launcher for TCL TV)

Lightweight (< 700 KB) Android TV launcher authored by Isllan Toso, using `tv_detox` as an initial architectural inspiration, redesigned for high performance on TCL hardware.

---

## Features

* Cold startup time < 150 ms.
* Zero advertisements, telemetry, or background services.
* Direct remote D-Pad navigation on a clean application grid.
* RAM footprint < 15 MB (compared to 250 MB on the stock Google TV LauncherX).

Binary releases are hosted at:
https://github.com/Isllanrx/OnlyTCL/releases/tag/v1.0.0
